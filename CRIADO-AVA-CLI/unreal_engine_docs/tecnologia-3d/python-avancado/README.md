# 🐍 Python Avançado: POO, APIs e Automação de Pipelines

Bem-vindo à subpasta de **Python Avançado**! Esta seção foi desenhada para levar você além dos scripts básicos de automação local, preparando-o para estruturar arquiteturas de software orientadas a objetos, integrar dados de APIs web complexas e automatizar fluxos de trabalho em softwares 3D (como Blender API - `bpy`).

---

## 🧭 Roteiro de Conteúdos Avançados

| Módulo | Assunto da Aula | Foco Prático |
| :--- | :--- | :--- |
| **Aula 1** | Programação Orientada a Objetos (POO) | Classes, herança, polimorfismo e métodos especiais (`__init__`, `__str__`). |
| **Aula 2** | Manipulação de Dados Estruturados | Leitura/escrita de arquivos JSON avançados, uso de pandas para tabelas de dados. |
| **Aula 3** | Conexão com Web APIs Complexas | Autenticação com chaves de API, tratamento de erros HTTP (`requests`, `try-except`). |
| **Aula 4** | Automação no Blender com Scripting (`bpy`) | Uso da API do Blender para gerar malhas 3D procedimentais via código Python. |

---

> [!TIP]
> **Por que integrar Python com Blender?**
> A API de Python do Blender (`bpy`) permite que você controle todas as funções do software por código. Você pode automatizar renderizações em lote, criar geradores de edifícios procedimentais ou importar dados externos do mundo real para renderizar gráficos tridimensionais.
