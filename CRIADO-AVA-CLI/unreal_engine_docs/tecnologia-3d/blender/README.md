# 🎨 Blender 3D: Modelagem, Escultura e Renderização

Bem-vindo à seção de **Blender**! Aqui você aprenderá a dominar o pipeline de computação gráfica 3D, desde a navegação na viewport tridimensional até a entrega de modelos otimizados para engines de jogos como a Unreal Engine.

---

## 🛠️ Tabela de Atalhos Fundamentais (Navegação 3D)

No Blender, o uso do teclado é essencial para velocidade de produção. Memorize estes comandos iniciais:

| Atalho | Ação Executada | Observação Importante |
| :--- | :--- | :--- |
| `Botão do Meio do Mouse (Scroll Clicado)` | **Rotacionar Viewport** | Gira a visualização ao redor do ponto central. |
| `Shift` + `Botão do Meio do Mouse` | **Mover Viewport (Pan)** | Move a câmera lateralmente ou verticalmente. |
| `Tab` | **Alternar Edit Mode / Object Mode** | O Edit Mode permite alterar vértices, arestas e faces. |
| `Z` | **Menu de Modos de Sombreamento** | Alterna entre Solid, Wireframe, Rendered e Material Preview. |

---

> [!TIP]
> **Dica de Otimização para Jogos:**
> Ao modelar ativos que serão importados para a Unreal Engine, sempre certifique-se de que a escala do objeto está aplicada (`Ctrl + A` -> `Apply All Transforms`) e o ponto de origem está posicionado na base do modelo.
