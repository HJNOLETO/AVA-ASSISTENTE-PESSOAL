Curso C++ para Unreal Engine

Do Zero à Programação de Jogos

Visão Geral e Roadmap de Aprendizado

Este curso foi cuidadosamente estruturado para levar um iniciante absoluto a um nível avançado de proficiência em C++ com foco em desenvolvimento para a Unreal Engine. Siga o roadmap abaixo para uma jornada de aprendizado eficiente e completa.

Estrutura e Níveis de Proficiência

O conteúdo está dividido em três níveis de proficiência, garantindo que você construa uma base sólida antes de avançar para tópicos mais complexos.

Módulo Nível Conceitos Chave Tempo Estimado Acesso
**01 - Fundamentos** Básico Variáveis, Operadores, Estruturas de Controle, Arrays, Strings. ~15 horas Iniciar Módulo
**02 - Intermediário** Intermediário Funções, Ponteiros, Referências, Memória Dinâmica, STL (Vector, Map, Set). ~25 horas Acessar Módulo
**03 - Avançado - POO** Avançado Classes, Objetos, Herança, Polimorfismo, Templates, Exceções, Conceitos Avançados. ~30 horas Acessar Módulo
**04 - Prática Unreal** Aplicação Macros Unreal, Tipos Unreal (TArray, FString), Actors, Components, Projeto Final. ~20 horas Acessar Módulo

Roadmap Detalhado de Conceitos

Abaixo, o detalhamento de **TODOS** os conceitos que você irá dominar, organizados por nível e com suas dependências.

Nível 1: Fundamentos (Pré-requisito: Nenhum)

1.1 Primeiros Passos Variáveis, Tipos Primitivos, Operadores, I/O, Casting.
1.2 Estruturas de Controle Condicionais (`if`, `switch`), Loops (`for`, `while`), `break`, `continue`, Ternário.
1.3 Estruturas de Dados Básicas Arrays Estáticos, Strings (C-style e `std::string`).

Nível 2: Intermediário (Pré-requisito: Nível 1)

2.1 Funções Declaração, Parâmetros, Retorno, Sobrecarga, Escopo.
2.2 Ponteiros e Referências Endereço de Memória, Operadores `&` e `*`, Passagem por Referência, Smart Pointers.
2.3 Memória Dinâmica Operadores `new` e `delete`, Vazamento de Memória.
2.4 Estruturas de Dados da STL `std::vector`, `std::map`, `std::set`, Iteradores.
2.5 Enumerações e Structs `enum class`, `struct` básicas.

Nível 3: Avançado e POO (Pré-requisito: Nível 2)

3.1 Classes e Objetos Definição, Atributos, Métodos, Encapsulamento, Construtores/Destrutores.
3.2 Herança e Polimorfismo Herança Simples/Múltipla, Funções Virtuais, Classes Abstratas.
3.3 Sobrecarga de Operadores Sobrecarga Aritmética, Comparação, I/O (`<<`, `>>`).
3.4 Templates Templates de Função e Classe, Especialização.
3.5 Exceções `try`, `catch`, `throw`, Hierarquia.
3.6 Conceitos Avançados Namespaces, Lambdas, Move Semantics, RAII, Const Correctness.

Nível 4: C++ Específico para Unreal Engine (Pré-requisito: Nível 3)

4.1 Fundamentos Unreal Macros (`UPROPERTY`, `UFUNCTION`), Tipos Unreal (`TArray`, `FString`), Sistema de Reflexão.
4.2 Componentes e Lógica de Jogo Actors, Components, Delegates, Timers, Garbage Collection (`UObject`).
4.3 Projeto Final Implementação de um jogo completo em Unreal Engine.
