Visão Geral do Módulo

Este módulo é o ponto de partida da sua jornada. Aqui, você aprenderá os blocos de construção essenciais de qualquer programa em C++: como armazenar informações (variáveis), como manipular essas informações (operadores) e como controlar o fluxo de execução do seu código (condicionais e loops).

💡 **Dica para Iniciantes:** A repetição é a chave. Não apenas leia o código, **escreva-o** e **execute-o** no seu computador. Entender os fundamentos é o que garantirá seu sucesso nos módulos mais avançados.

Estrutura de Cada Lição

Cada lição (subpasta) segue um padrão para maximizar seu aprendizado:

  • **`teoria.md`**: Explicação detalhada, analogias e como o conceito se aplica em jogos.
  • **`exemplos.cpp`**: Código funcional com comentários linha por linha.
  • **`exercicios.md`**: Desafios para testar sua compreensão.
  • **`exercicios-resolvidos.cpp`**: Soluções comentadas para os exercícios.
  • **`quiz.html`**: Quiz interativo para autoavaliação.
