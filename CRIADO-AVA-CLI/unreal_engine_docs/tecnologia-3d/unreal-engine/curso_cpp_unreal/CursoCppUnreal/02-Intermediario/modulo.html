Visão Geral do Módulo

Parabéns por chegar ao Módulo 02! Agora você vai aprender os conceitos intermediários que separam programadores iniciantes dos profissionais. Este módulo foca em como organizar código em funções reutilizáveis, como gerenciar memória de forma eficiente e como usar as estruturas de dados poderosas da Standard Template Library (STL).

💡 **Conceito Chave:** Ponteiros são um dos tópicos mais importantes do C++. Dedique tempo para realmente entendê-los, pois eles são a base para programação avançada e desenvolvimento em Unreal Engine.

Estrutura de Cada Lição

Cada lição segue o mesmo padrão estabelecido no Módulo 01, com adição de exemplos mais complexos:

  • **`teoria.md`**: Conceitos aprofundados com diagramas mentais e analogias.
  • **`exemplos.cpp`**: Código funcional demonstrando cada conceito.
  • **`exercicios.md`**: Desafios progressivos (Fixação, Aplicação, Desafio).
  • **`exercicios-resolvidos.cpp`**: Soluções comentadas.
  • **`quiz.html`**: Autoavaliação interativa.

Tópicos Principais

1. Funções Declaração, Definição, Parâmetros, Retorno, Sobrecarga, Escopo.
2. Ponteiros e Referências Endereço de Memória, Operadores `&` e `*`, Passagem por Referência, Ponteiros para Funções.
3. Memória Dinâmica Operadores `new` e `delete`, Vazamento de Memória, Smart Pointers (Introdução).
4. STL Containers Vector, Map, Set, Stack, Queue, Iteradores, Algoritmos.
