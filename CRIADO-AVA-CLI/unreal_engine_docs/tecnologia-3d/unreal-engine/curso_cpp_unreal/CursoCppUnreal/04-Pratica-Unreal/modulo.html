Visão Geral do Módulo

Parabéns! Você chegou ao Módulo Final, onde toda a teoria de C++ se transforma em prática dentro da Unreal Engine. Este módulo é dedicado a entender como a Unreal estende o C++ com suas próprias macros, tipos de dados e sistemas, permitindo que você crie jogos profissionais.

⚠️ Pré-requisito: Você deve ter a Unreal Engine instalada para acompanhar este módulo.

Tópicos Principais

1. Setup e Conceitos Unreal Ambiente de desenvolvimento, Unreal Build Tool, Sistema de Reflexão, Garbage Collection.
2. Tipos Unreal e Macros FString, FName, FText, TArray, TMap, UPROPERTY, UFUNCTION, USTRUCT.
3. Projeto Final FPS Arquitetura de um FPS, Componentes, Actors, Polimorfismo em Unreal.

Projeto Integrador Final

Ao final deste módulo, você criará um Sistema de Interação e Inventário.
