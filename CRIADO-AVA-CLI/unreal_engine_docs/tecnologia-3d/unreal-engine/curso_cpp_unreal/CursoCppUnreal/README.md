# Curso de C++ para Unreal Engine: Do Zero ao Jogo

Bem-vindo ao seu guia completo e progressivo para dominar a linguagem C++ com foco no desenvolvimento de jogos na Unreal Engine. Este curso é projetado para **iniciantes absolutos**, sem conhecimento prévio de programação, e o levará desde os fundamentos da linguagem até a aplicação prática de conceitos avançados e específicos da Unreal Engine.

## Estrutura do Curso

O curso está dividido em quatro módulos principais, seguindo uma progressão lógica de aprendizado:

| Módulo | Foco Principal | Nível | Tempo Estimado |
| :--- | :--- | :--- | :--- |
| **01 - Fundamentos** | Sintaxe básica, variáveis, operadores e estruturas de controle. | Básico | 15 horas |
| **02 - Intermediário** | Funções, Ponteiros, Memória Dinâmica e a Standard Template Library (STL). | Intermediário | 25 horas |
| **03 - Avançado - POO** | Programação Orientada a Objetos (Classes, Herança, Polimorfismo) e conceitos avançados. | Avançado | 30 horas |
| **04 - Prática Unreal** | Aplicação de C++ no contexto da Unreal Engine, tipos específicos e projeto final. | Aplicação | 20 horas |

## Como Usar Este Material

1.  **Navegação:** Comece pelo `index.html` para ter uma visão geral e acessar o **Roadmap de Aprendizado**.
2.  **Conteúdo:** Cada seção possui arquivos `teoria.md` (explicações detalhadas), `exemplos.cpp` (código funcional e comentado) e `exercicios.md` (desafios para fixação).
3.  **Prática:** É crucial executar e modificar os arquivos `.cpp` para entender o funcionamento do código.
4.  **Avaliação:** Utilize os `quiz.html` para testar seu conhecimento após cada subseseção.
5.  **Projetos:** Os projetos integradores e o projeto final são a chave para consolidar o aprendizado.

## Pré-requisitos

*   Um computador com capacidade para rodar a Unreal Engine (recomendado).
*   Um editor de código (como VS Code ou Visual Studio).
*   Um compilador C++ (como GCC ou Clang).
