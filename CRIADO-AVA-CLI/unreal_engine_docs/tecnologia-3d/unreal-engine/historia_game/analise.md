Sobre a repetição de informações

Pleonasmo é a repetição de uma mesma ideia por meio de palavras diferentes, podendo ser um recurso estilístico ou um vício de linguagem.
O pleonasmo ocorre quando se repetem ideias no mesmo enunciado usando palavras diferentes que têm o mesmo sentido. Quando essa repetição é intencional, é chamada de pleonasmo literário ou expressivo, sendo usada para dar ênfase, reforçar a mensagem ou criar efeito poético, como em: “E rir meu riso e derramar meu pranto” (Vinicius de Moraes) ou “As doces águas do rio embelezavam a paisagem”
