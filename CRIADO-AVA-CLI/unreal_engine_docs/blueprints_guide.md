# Blueprints no Unreal Engine

## O que são Blueprints?
Blueprints são um sistema de scripting visual baseado em nós (nodes) que permite criar lógicas de jogo, interações e comportamentos sem a necessidade de escrever código C++ manualmente.

## Como Funcionam?
- **Nós (Nodes):** Representam funções, eventos ou variáveis.
- **Conexões (Wires):** Definem o fluxo de execução e a passagem de dados entre os nós.
- **Event Graph:** Onde a lógica principal é construída.

## Vantagens
1. **Iteração Rápida:** Alterações podem ser feitas e testadas em tempo real.
2. **Acessibilidade:** Permite que designers e artistas implementem mecânicas.
3. **Integração:** Podem coexistir com C++, onde o C++ lida com performance e Blueprints com ajustes finos.

## Casos de Uso Comuns
- Trigger de portas abrindo.
- Sistemas de inventário simples.
- Controle de movimentação de personagens.
- Interface de Usuário (UMG).
